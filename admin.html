Espace de gestion

Gérer le site du groupe.

Modifie les textes, les photos, les dates et les liens. À la fin, le panneau crée une branche GitHub et ouvre une Pull Request : les changements ne sont pas publiés tant que tu ne les as pas acceptés sur GitHub.

Connexion à GitHub

Le site étant statique, l’administration utilise un jeton GitHub que tu fournis pour cette session. Le jeton reste en mémoire dans cet onglet et n’est jamais enregistré dans le dépôt ni dans le stockage du navigateur.

Permissions nécessaires : crée un jeton à granularité fine limité uniquement au dépôt pika18385-maker/Bommers-crooners, avec Contents: Read and write et Pull requests: Read and write. Ne colle jamais le jeton dans une conversation, un fichier ou un dépôt. Le panneau ne réutilise pas le mot de passe partagé précédemment, car un mot de passe écrit dans le JavaScript d’un site public ne serait pas secret.

Contenu du site

Renseigne uniquement les informations officielles du groupe. Les champs vides pour les coordonnées restent absents du site public.

Concerts et événements

Tu peux ajouter autant de dates que nécessaire. Les événements sans lien de réservation affichent tout de même leur date, leur titre et leur lieu.

Galerie photo

Les images par URL sont possibles. Pour envoyer une photo depuis ton appareil, choisis un fichier JPG, PNG ou WebP de 4 Mo maximum ; il sera ajouté au dépôt dans la branche de proposition.

Avant de terminer

Le bouton ci-dessous envoie les changements dans une nouvelle branche, puis demande une Pull Request vers main. Rien n’est fusionné automatiquement. Sur GitHub, tu pourras vérifier les changements, puis fusionner la PR pour les accepter ou la fermer pour les refuser.

Après la création d’une Pull Request, termine son examen sur GitHub avant de refaire une nouvelle modification. Si tu fusionnes la PR, recharge ensuite cette page et reconnecte-toi pour repartir de la dernière version publiée.
